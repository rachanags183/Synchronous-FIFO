Synchronous FIFO using SystemVerilog

Project Description

This project implements a Synchronous FIFO (First-In First-Out) memory using SystemVerilog. It stores and retrieves data in the order it is written.

Features

- 8-bit data width
- FIFO depth of 4
- Synchronous read and write operations
- Reset functionality
- Full and Empty status flags

Files Included

1. "synchronous_fifo.sv" – FIFO design source code.
2. "tb_synchronous_fifo.sv" – Testbench for verifying FIFO functionality.

Test Cases

- Reset operation
- Writing data into FIFO
- Reading data from FIFO
- Checking FIFO Full condition
- Checking FIFO Empty condition
- Simultaneous read and write operations

Tools Used

- SystemVerilog
- EDA Playground / HDL Simulator
- GitHub

Expected Output

The simulation verifies correct FIFO operation, data storage, data retrieval, and Full/Empty flag conditions.
